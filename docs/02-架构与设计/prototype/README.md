# prototype —— k8s-ai 前端原型（四期·平台化）

本目录是**整个 k8s-ai 产品**的前端静态原型，用于在动手实现前对齐交互、信息架构与渲染规范。

## 打开方式

直接用浏览器打开 `prototype/index.html`（双击即可，**无构建、无外部依赖**），或：

```powershell
start .\prototype\index.html
```

## 包含什么

- `index.html` —— 可交互产品原型，覆盖全部 9 个页面（登录 / 聊天 / 集群 / 审批中心 / 审计 / Skill / 配置中心 / 用户与权限 / 管理控制台）。
- `01-前端设计方案-k8s-ai-平台化.md` —— 设计基线（信息架构、聊天核心交互、结构化渲染、markdown/XSS、组件清单、落地映射）。

## 原型内可交互点

- 侧栏切换九个页面；右上角 ◐ 切换深/浅主题（默认深色，修复「分组展开白色」问题）。
- 右上角用户菜单（点击 avatar）：展示角色、平台版本与当前集群，并提供「退出登录」（回显登录页）。
- 顶栏 ☰ 收起/展开主侧栏（→ 60px 图标栏，tooltip 兜底）；聊天页会话头 ≪ 独立收起会话栏（240px → 56px）。
- 聊天页：底部「▶ 演示回合」会演示完整回合生命周期——思考面板展开（流式）→ 工具卡执行 → 结构化结果 → 最终报告 markdown → 整组合并为摘要。
- 工具卡点头部展开/收起；审批卡可「拒绝 / 确认并执行」；会话可新建/选择/删除。
- 用户与权限 / 审批中心可打开抽屉（namespace 授权、审批详情）。

## 迭代流程（与四期联动）

1. 评审原型不合理处 → 先改 `01-前端设计方案-*.md`，再同步改 `index.html` 对应视图。
2. 方案与原型定稿后，按方案 §10 落地，映射到四期任务 `P2.7–P2.13`。
3. 原型**不进入 `web/` 实现**，不作为运行时产物；它是设计与确认工具。

## 与老 UI 的关系

不照搬 `internal/webui/index.html` 的像素样式，但保留并组件化它的**结构化渲染能力**（表格 / KV / 事件 / YAML / 日志 / markdown），见方案 §6 映射表。
