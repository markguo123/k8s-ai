# k8s-ai 文档中心

k8s-ai 是面向 Kubernetes 的智能巡检、故障诊断与自然语言运维 Agent 项目。本文档中心按「面向谁、解决什么」组织文档，正文一律 Markdown，可执行产物与静态素材统一放 `assets/`。

## 目录导航

| 目录 | 内容 | 面向读者 |
|---|---|---|
| `01-产品与需求/` | 需求文档（PRD）、原型与交互说明、需求规格、宣讲材料 | 产品经理 / 业务方 / 决策者 |
| `02-架构与设计/` | 系统架构、数据模型、API、ADR、安全/并发/性能等设计、专题方案 | 架构师 / 开发 |
| `03-运维与部署/` | 部署安装、E2E 冒烟验证 | 运维 / DevOps |
| `04-项目管理与规范/` | 版本与发布规则、项目状态、变更记录、版权声明、开发计划 | 项目经理 / 团队 |
| `05-使用与操作手册/` | 技术指导手册、面向使用者的操作说明 | 交付 / 客服 / 使用者 |
| `99-归档/` | 过期、废弃、被替代的历史文档 | 所有人（仅供参考） |
| `assets/` | 图片、架构图、表格等静态资源 | - |

## 命名规范

- 目录：`NN-中文名`，`NN` 为两位数字前缀，控制阅读顺序，`00`–`98` 留白备用。
- 文件：`NN-主题.md`，两位数字前缀保证同目录内排序；文件名不写版本号与状态，统一写在文档开头的元信息块（版本 / 日期 / 状态 / 依据）。
- 素材：`assets/` 按类型下设子目录（如 `images/`），不参与编号。
